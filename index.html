☁ Set up cloud sync
One-time setup (~5 min). Your data lives in your own Google/Firebase account — nothing is shared.
1. console.firebase.google.com → Create project (any name, skip Analytics)
2. Click </> (Web) → Register app → copy the firebaseConfig block
3. Left menu → Build → Realtime Database → Create database → Start in test mode
4. Left menu → Build → Authentication → Get started → Google → Enable → Save
5. Authentication → Settings → Authorized domains → Add your-username.github.io
6. Paste your firebaseConfig below:
Sign in to sync
Your data is encrypted to your Google account. Only you can access it.
